What I built

  • Built a three-tier arXiv search system for a CMU Distributed Systems course: an Android client calls a Java servlet on Tomcat (WAR, Docker) that queries the arXiv API and summarizes abstracts with a custom extractive summarizer, logging each request to MongoDB Atlas for a dashboard of request count, average latency and top search term.
  • Limits, as stated in the repository: a single servlet service rather than a set of separate services, a word-frequency summarizer rather than a model, only request logs stored, and no deployed instance.
