MARS-Inspired Healthcare

Healthcare AI evaluation, 2026, Personal project, built at a hackathon and then deployed

30 of 30streamed questions answered on Cloud Run with no errors; p50 5,427 ms and p95 10,776 ms per answer, 984 ms median retrieval

What I built

  • Built a healthcare-AI evaluation assistant over a 15,954-row clinical corpus as nine event-driven Python services: a rule router sends each question to SQL and full-text search, Qdrant vector search or a graph leg, an open-weights Gemma model streams the answer, and a citation guard ties each item to its source paper.
  • Deployed the stack on GCP Cloud Run with Terraform, Docker and GitHub Actions CI (154 tests), instrumented with OpenTelemetry (Cloud Trace and Cloud Monitoring), behind a default-deny API with per-IP rate limits, a daily question cap and a non-root container.
  • Measured 30 streamed questions at two at a time on a warm instance: 30 of 30 answered, retrieval p50 984 ms and p95 1,498 ms, time to first token p50 2,033 ms and p95 5,993 ms, total p50 5,427 ms, p95 10,776 ms and p99 11,202 ms (n = 30, so p99 is the maximum), at about $0.0004 per question.
  • Measured retrieval with a reproducible harness on 40 faceted questions with SQL-derived gold: hybrid retrieval scored MRR@8 0.850 against 0.215 for dense search alone (0.963 at depth 20), and a seeded random-vector control scored 0.000.
  • Limits, as measured: the graph leg added nothing on this suite, BM25 scored 1.000 only because the gold is built from the same filters, no semantic or human-judged result exists, and the corpus fields are LLM extraction records, not ground truth.
  • In the cloud the nine services share one container on an in-memory bus, and a cold start after idle takes about two minutes. An Azure migration was designed first (Container Apps, Azure OpenAI in Azure AI Foundry, Managed Redis, Key Vault); it was not deployed.

A healthcare-AI evaluation assistant, deployed: nine event-driven services on GCP Cloud Run (Terraform, CI, OpenTelemetry), hybrid retrieval over 15,954 records, streamed answers with cited sources, and a retrieval harness with a random-vector control.
